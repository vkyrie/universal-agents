# Eval: Small Shop in Pakistan Selling Online

## Question
> Should a small shop in Pakistan start selling online?

## Expected Verdict
**Yes, but lean test first — not a full store at once.**
- Start on existing platforms: Daraz.pk (marketplace), Instagram/Facebook shop, WhatsApp Business with Cash on Delivery (COD).
- Test demand with a 90-day budget ($200–$500 for ads + platform fees) and a kill criterion (e.g., CAC > PKR 3,000 or ROAS < 2.0).
- Only after the test validates unit economics: build a dedicated store (Shopify/WooCommerce) or scale on Daraz.
- Key conditions (agent's test rules, not sourced evidence):
  - Gross margin sufficient to absorb platform fees (~2–5%), shipping, returns, CAC.
  - Average order value (AOV) supports per-order costs.
  - Fulfillment capacity exists (can pack/ship 10–20 orders/day) or budget for 3PL.
- Do NOT proceed if: margins are thin (< 40%), no fulfillment capacity, already cash-flow negative.

## Expected Confidence
MODERATE

## What Would Fail This Eval
- **Wrong direction:** Verdict says "No, don't sell online" or "Yes, immediately build a full custom store" without a lean test phase.
- **Confidence too high:** HIGH confidence when expected is MODERATE.
- **CONFIRMED without URL:** Any claim labelled CONFIRMED without a retrievable primary source URL (e.g., a specific margin threshold like "≥50%" presented as evidence rather than an agent's test rule).
- **Invented source:** Any source, statistic, or citation that cannot be retrieved (e.g., a fake "Pakistan e-commerce study" with specific numbers, a non-existent Daraz fee schedule).
- **Missing uncertainty:** Verdict does not explicitly state the uncertainty (e.g., does not mention that no primary Pakistan-specific small-shop data was retrieved, that thresholds are agent's test rules not sourced evidence, that CAC/returns vary wildly by category).
